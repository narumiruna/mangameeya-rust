四案共用的操作

  • 方案 04 預設顯示閱讀畫面；早期三案預設顯示瀏覽畫面。上方模式控制可返回瀏覽或繼續閱讀。選取書籍後，按「開啟選取」、Enter 或雙擊書籍進入閱讀。
  • 方案 04 左側保留檔案／縮圖／最近閱讀；右側「瀏覽」分頁提供封面大小、檔名與中繼資料控制。兩個側欄可分別切換顯示。
  • 閱讀中按 Backspace 返回同一資料夾；瀏覽中按 Backspace 返回上一層，在根目錄不動作。編輯輸入欄位時不攔截此按鍵。
  • 提供示範資料夾導覽、搜尋，以及名稱自然／字面、修改日期、建立日期、大小、類型、頁數、閱讀進度、最近閱讀、固定種子的隨機排序。升冪／降冪與「資料夾優先」分別控制。
  • 同一頁面生命週期內保留閱讀進度與瀏覽狀態，包括捲動、排序、篩選及選取；重新載入後重設，不使用持久儲存。

這是介面原型，不是原生功能

所有書籍、封面與檔案資訊均為模擬資料，不讀取檔案系統，不修改 Rust 程式。

src/ui.rs 目前已有側邊欄的檔案瀏覽；方案 04 評估的是只切換中央畫布、保留既有視窗外框的結構。src/book.rs 已有自然排序與資料夾優先，本次多欄位排序僅在 HTML 原型示範，不代表原生功能已新增。

比較頁與四個原型均可離線開啟，共用本機 prototype.js 與 shared.css；方案 04 另需 integrated.css，請保留整個目錄。方案 04 的原生選單列與既有閱讀模式／縮放控制僅為靜態視覺示意，不代表已實作功能。原型不驗證原生 GPUI、檔案系統、OS 整合、無障礙或效能。操作與驗證步驟見 README.md。
