# MangaMeeya 檔案瀏覽介面提案

## 目前建議：04 整合式中央瀏覽區

[開啟方案 04](04-integrated.html)。依兩張新參考截圖修正：既有 MangaMeeya 的上方選單／工具列、左側內容導覽、右側閱讀工具與底部分頁／進度狀態列維持原位。閱讀中按 Backspace，只有中央漫畫畫布改為黑底封面／檔案網格；按 Enter 或雙擊書籍開始閱讀新書。不是獨立書庫頁，也不是模態覆蓋層。

方案 01 的封面網格與方案 03 的閱讀情境接近需求，但前三案均未準確表達視窗結構。方案 04 將兩者收斂到中央區域，不沿用方案 03 的覆蓋方式。

## 開啟方式與早期比較

以瀏覽器開啟 `index.html`，先查看目前建議方案，再比較早期三案。不需要安裝套件或啟動伺服器。

1. [04 整合式中央瀏覽區](04-integrated.html)：目前建議方向，保留既有視窗外框，只切換中央內容。
2. [01 封面書庫](01-grid.html)：早期深色全頁封面網格，保留作封面呈現比較。
3. [02 詳細檔案總管](02-explorer.html)：早期淺色三欄設計，保留作中繼資料比較。
4. [03 閱讀上層書庫](03-switcher.html)：早期暖色全高覆蓋層，保留作閱讀情境比較，非目前建議結構。

`index.html` 的縮圖是原創 HTML / CSS 結構示意，不是畫面截圖。封面僅使用原創向量圖；參考截圖未嵌入或複製。比較頁使用內嵌樣式；四個操作原型共用本機 `shared.css` 與 `prototype.js`，方案 04 另需 `integrated.css`，不是各自獨立的單檔 HTML。請保留整個目錄。所有樣式與腳本均在本機，使用系統字型，不需要網路或二進位資源。

## 共用操作規格

- 方案 04 預設顯示閱讀畫面；早期三案預設顯示檔案瀏覽畫面。
- 上方模式控制可返回瀏覽或繼續閱讀，與 Backspace 共用閱讀／瀏覽狀態。
- 方案 04 左側提供檔案／縮圖／最近閱讀分頁；右側「瀏覽」分頁提供封面大小、檔名與中繼資料顯示控制。
  - 兩個側欄顯示切換按鈕分別控制左、右面板。
  - 原生選單列與既有閱讀模式／縮放控制僅為靜態視覺示意，不是已實作功能。其餘控制的驗證結果見下方紀錄。
- 選取書籍後，按「開啟選取」、Enter 或雙擊書籍進入閱讀；方案 02 也可按預覽區的「開始閱讀」。
- Backspace 依目前畫面執行：
  - 閱讀畫面：返回開啟書籍時的同一資料夾。
  - 瀏覽畫面：返回上一層；根目錄不動作。
  - 可編輯輸入欄位：不攔截按鍵，保留文字編輯行為。
- 提供示範資料夾導覽與搜尋。
- 排序欄位包括名稱自然排序、名稱字面排序、修改日期、建立日期、大小、類型、頁數、閱讀進度、最近閱讀與固定種子的隨機順序。
  - 自然排序用數字值比較名稱中的數字，例如第 2 集先於第 10 集；字面排序依文字順序比較。
  - 可切換升冪與降冪。
  - 「資料夾優先」是獨立核取方塊；啟用時，升冪與降冪都把資料夾置前。
  - 缺少中繼資料的項目在同一分組內置後，不受升冪與降冪影響。
  - 固定種子的隨機順序用於重現結果，不是每次重新繪製都洗牌。選擇隨機排序後，可按洗牌按鈕產生新順序。
- 同一頁面生命週期內保留閱讀進度、瀏覽捲動、排序、搜尋篩選與選取狀態。
  - 在閱讀與瀏覽之間切換時還原狀態。
  - 不使用持久儲存；重新載入頁面後重設。

## 與現有 Rust 程式的界線

本目錄仍是使用模擬資料的 HTML 設計參考。原生中央瀏覽已另於 `src/ui/browser.rs`、`src/browser.rs` 與 `src/book/cover.rs` 實作；實際操作見 repository 的 README，原生測試證據與限制見 [verification.md](../verification.md)。以下 387 項紀錄只驗證 HTML，不取代原生測試。

- `src/ui.rs` 已有側邊欄，其中 `SidebarMode::Files` 使用 `render_files` 顯示檔案。方案 04 評估既有視窗外框內的中央閱讀／瀏覽切換；早期三案保留作歷史比較，不是已完成的原生側邊欄改版。
- `src/book.rs` 的頁面排序已使用 `natord::compare_ignore_case`；`browse_directory` 已先排資料夾，再使用名稱自然排序。原型的多欄位排序不代表 Rust 已支援這些選項。
- 書籍、封面、資料夾、日期、大小、頁數與進度均為模擬資料。原型不讀取真實檔案系統，不寫入閱讀紀錄，不修改原生 Rust 行為。

## 可重現的手動檢查

依序在四個操作原型執行下列檢查；方案 04 先確認預設閱讀畫面，再按 Backspace 進入中央網格。每案開始前重新載入，使用同一組示範資料比較。記錄瀏覽器、視窗尺寸、操作與實際結果；本清單不是通過紀錄。

1. **離線開啟與版面**
   - 停用網路，以本機檔案開啟 `index.html`，逐一開啟四個方案連結。
   - 確認本機樣式與腳本可載入，沒有外部字型或圖片需求。
   - 比較寬視窗與窄視窗；確認比較頁可閱讀、連結可操作，早期三案結構各有區別；方案 04 切換中央內容時，選單、工具列、左右面板與底部狀態列保持原位。
2. **進入閱讀與返回**
   - 從示範根目錄進入含書籍的子資料夾，選取書籍，記下路徑與選取項目。
   - 分別用「開啟選取」、Enter、雙擊書籍開啟閱讀，每次以 Backspace 返回。
   - 確認返回同一資料夾，而非根目錄或瀏覽器上一頁。
3. **上一層與文字輸入**
   - 在子資料夾的非編輯區按 Backspace，確認回到上一層；在根目錄再按一次，確認沒有動作。
   - 在搜尋欄輸入文字後按 Backspace，確認刪除文字，不切換資料夾。
4. **搜尋與選取**
   - 輸入一個現有書名片段，確認結果縮小；輸入不存在的文字，確認顯示空結果而非錯誤。
   - 清除搜尋，確認清單恢復；選取書籍，確認封面、詳細資料或選取樣式對應該書。
5. **所有排序欄位**
   - 逐一選取名稱自然、名稱字面、修改日期、建立日期、大小、類型、頁數、閱讀進度、最近閱讀與隨機排序。
   - 使用名稱含數字 2 與 10 的示範項目，比較自然與字面順序。
   - 每個欄位分別檢查升冪、降冪；固定種子的隨機排序切離再切回，確認相同狀態下順序可重現。
   - 分別勾選與取消「資料夾優先」；勾選時確認升冪、降冪都把資料夾置前。
6. **頁面內狀態還原**
   - 設定非預設排序、搜尋條件與資料夾優先狀態，捲動清單並選取可閱讀的書籍；記錄這些值。
   - 開始閱讀，變更閱讀頁數，按 Backspace 返回，確認路徑、捲動、排序、篩選與選取還原。
   - 再開啟同一本書，確認閱讀進度保留。對方案 03 另確認閱讀背景與覆蓋層的關係；方案 04 確認沒有覆蓋層或獨立書庫頁，並檢查上方返回／繼續閱讀控制、左右側欄切換與瀏覽顯示設定。
   - 重新載入，確認回到示範初始狀態，沒有跨頁面生命週期的持久儲存。
